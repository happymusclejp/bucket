# CLF-C02 クエスト

AWS Certified Cloud Practitioner (CLF-C02) の勉強を、ゲーム感覚で続けるためのブラウザアプリです。
ビルド不要。`index.html` をブラウザで開くだけで動きます。

## できること

| モード | 内容 |
| --- | --- |
| ミックス10問 / ドメイン別10問 | 未回答・不正解の問題を優先して出題。1問ごとに解説つき |
| ミニ模試 | 本番の配点(24/30/34/12%)どおり20問・28分。最後にまとめて採点 |
| サービス早押し | 説明文からサービス名を4択で当てる60秒ゲーム。ミスすると -3秒 |
| サービス単語帳 | 79サービスのフラッシュカード。「名前→説明」「説明→名前」を切り替え可 |
| 苦手復習 | 最後にまちがえた問題だけを解き直す |

XP・レベル(称号は Free Tier → … → Cloud Practitioner)、連続学習日数、1日20問の目標、バッジ、
配点で重み付けした「合格準備度」でモチベーションを保てるようにしています。

## ファイル構成

- `index.html` … 画面とスタイル
- `app.js` … ロジック(出題、採点、XP、保存など)
- `data.js` … 問題92問とサービスカード79枚。ここに追記すれば問題を増やせます

```js
// 問題の形式 (a は正解の選択肢インデックス。複数選択なら2つ入れ、問題文に「2つ選んで」と書く)
{ id: 'c18', d: 1, q: '問題文', o: ['選択肢A', 'B', 'C', 'D'], a: [0], e: '解説' }
```

## メモ

- 学習記録はブラウザの localStorage に保存されます(端末・ブラウザごとに別々)。
- 問題はオリジナルで、試験ガイドの範囲に沿って作っています。サポートプランなど改定されやすい内容は、公式情報も確認してください。
